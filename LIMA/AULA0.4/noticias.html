O HTML está substituindo o JavaScript? Conheça as novas funções nativas que mudam tudo

Se você cria sites, sabe que o JavaScript sempre foi o "rei" na hora de criar interações, como menus que abrem e fecham ou janelas flutuantes. Mas o jogo está mudando! O HTML está recebendo superpoderes e agora consegue fazer sozinho coisas que antes exigiam muito código.A grande novidade do momento é a Popover API. Ela permite que qualquer pessoa crie alertas, menus e caixas de diálogo usando apenas atributos simples direto no HTML, sem precisar de nenhuma linha de JavaScript para fazê-los aparecer ou sumir.

O comando HTML secreto que acelera o carregamento do seu site no Google

A velocidade de um site não é importante apenas para o usuário que está navegando, mas também para o Google. O motor de busca mais famoso do mundo penaliza sites lentos e premia os mais rápidos. Se você quer melhorar o desempenho das suas páginas sem quebrar a cabeça, precisa conhecer o atributo fetchpriority.Essa novidade do HTML serve para dar uma "ordem" direta ao navegador sobre o que ele deve carregar primeiro quando alguém acessa o seu site.

O segredo do Banner Principal (LCP)

O Google mede a velocidade de um site baseado, principalmente, no tempo que a maior imagem da tela demora para aparecer (métrica conhecida como LCP ou Largest Contentful Paint). Geralmente, essa imagem é o banner principal ou a foto de destaque de um artigo.Se o seu site tiver muitos scripts de anúncios ou ícones pesados, o navegador pode se perder e demorar para baixar a imagem principal. É aí que entra o fetchpriority="high".Ao colocar esse comando direto na tag da sua imagem principal, você avisa ao navegador: "Atenção! Esqueça o resto por um segundo e baixe essa imagem antes de tudo!".

W3C atualiza regras de HTML e muda a forma como criamos sites acessíveis

Criar um site bonito e rápido já não é o suficiente para o mercado atual. Hoje, a palavra de ordem na internet é acessibilidade. O W3C (consórcio global que define as regras de como a internet deve funcionar) lançou uma atualização crucial em seu guia oficial de ARIA no HTML.O ARIA (Accessible Rich Internet Applications) é um conjunto de atributos especiais que adicionamos ao código para ajudar tecnologias assistivas — como os leitores de tela usados por pessoas cegas — a entenderem o que está acontecendo na página.

O que muda com a nova atualização?

Com a internet evoluindo e o HTML ganhando novas tags nativas (como diálogos e menus flutuantes), as regras antigas precisavam mudar para evitar conflitos. A nova atualização deixa claro o que os desenvolvedores podem e não podem fazer ao misturar atributos ARIA com as novas tags do HTML.O objetivo principal é evitar a "superficialidade". Muitos programadores colocam códigos de acessibilidade errados achando que estão ajudando, mas acabam confundindo os leitores de tela. As novas diretrizes barram esses excessos.
